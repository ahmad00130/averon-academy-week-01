# Week 1 Reflection

## 1. What did I learn this week?

I learned how to set up a professional GitHub repository from scratch, write documentation in Markdown, and make meaningful commits with clear messages. I also learned how a local project connects to a remote repository, and why version history matters.

## 2. What was difficult for me?

I ran into errors when running commands in PowerShell, because some file-creation commands only work in Git Bash. I also got confused about which folder I was in when connecting my project to GitHub.

## 3. How did I solve the problem?

I read the error messages carefully, found out that PowerShell uses different syntax from Git Bash, switched to the PowerShell version of the commands, and checked my folder location before running the next step.

## 4. What do I still need help with?

I still need help with writing consistently good commit messages, working with branches, and resolving merge conflicts. I also want to get more comfortable using Git from the terminal without relying on step-by-step instructions.

## 5. What am I looking forward to learning next?

I'm looking forward to learning Python, building real projects, and going deeper into cybersecurity so I can build apps that are safe to use.
