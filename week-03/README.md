# Interactive Greeting App

A simple webpage built with HTML, CSS, and JavaScript that welcomes visitors by name.
Part of Averon Academy, Week 3.

## Features
- Input field and button to enter a name
- Personalized greeting shown without reloading the page
- Friendly error message when the input is empty
- Greeting changes with the time of day (morning, afternoon, evening)
- Live character counter
- Button to change the background color
- Button to display the current date
- Press Enter to submit
- Dark/light mode toggle (saved in the browser)
- Live clock
- Greetings in English, Hausa, Yoruba, Igbo, French and Spanish
- Name validation (letters only)
- Remembers your last name, language and theme using localStorage
- Random motivational quote button
- Clear button
- Recent greetings history

## How to Run
1. Clone the repository: `git clone https://github.com/ahmad00130/averon-academy-week-01.git`
2. Open the `week-03` folder
3. Open `greeting.html` in any web browser

## Project Structure
- `greeting.html`: page structure
- `style.css`: styling
- `script.js`: interactivity
- `README.md`: project description

## What I Learned
- Selecting elements with `document.querySelector()`
- Responding to events with `addEventListener()`
- Reading input values and updating text with `textContent`
- Using conditionals and functions to make decisions and reuse code
- Saving data in the browser with `localStorage`
