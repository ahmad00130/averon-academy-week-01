# Posts Explorer (Week 4)

A responsive webpage that fetches posts from the [JSONPlaceholder API](https://jsonplaceholder.typicode.com/posts) and lets users explore them.

## Features
- Fetches posts dynamically with `fetch()` and `async/await`
- Loading, empty-result, and error states
- Search posts by title
- Filter posts by user ID
- Reload button to fetch the data again
- Responsive layout for mobile and desktop

## Tech Stack
HTML, CSS, and vanilla JavaScript (no frameworks)

## How to Run
1. Clone the repository
2. Open the `week-04` folder
3. Open `posts.html` in your browser (or use the VS Code Live Server extension)

## What I Learned
- Selecting and updating the DOM
- Handling events with `addEventListener`
- Working with APIs and JSON
- Handling errors with `try/catch`
